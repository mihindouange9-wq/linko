# Surface: LINKO home (app/page.tsx)

Mode: Persuade. Visitors: people with an urgent need, companies needing skills, professionals who want clients (French-speaking Africa, mostly on phones). Action: describe a need / create a pro profile. Proof: demonstration only (labelled fictitious); no invented figures.

## Direction contract

THESIS: LINKO is the city's répertoire, the address book where people keep the number of « le bon électricien ». A ruled line links a need to a name. Refuses the marketplace default (centered search hero, icon category grid, phone mockup) and the network-graph cliché.

OWN-WORLD: Off-white (#F5F4EF) pages ruled with soft grey hairlines (#E8EAE7), obsidian (#111315) ink and obsidian spreads, slate (#667078) secondary. Green (#20C77A / #087A4B for text) appears only as a signal: available, matched, active, primary action. A single variable grotesque (Mona Sans, wght + wdth), tabular figures, entries set on the rules. A thumb index on the right edge (tabs per chapter) is the navigation, with one green témoin marking where you are. No paper texture, no cards-as-structure, no gradients.

STORY: I recognise my reality (asking around, dead numbers) → I watch LINKO find the right person for a need → I trust what a profile shows → I search, or as a pro I create my profile.

FIRST VIEWPORT: Header (logo left; « Je suis professionnel » + « Décrire un besoin » right). « Un besoin. » top-left and « La bonne compétence. » lower-right, display scale, each sitting on its own ruled line. Between them, the two halves of the LINKO symbol drift separately: obsidian = the need (labelled with a real request), green = the skill (labelled with a trade entry). Cursor proximity makes them lean together; scroll interlocks them into the logo. The primary action sits on the bottom rule: « J'ai besoin d'un… » input + « Trouver » button + trade suggestions. Thumb index on the right edge.

FORM: Le Répertoire, candidate 5 of my grounded list, seed key 31d41335. Raises: variable weight tracks match confidence (from Variable Font Specimen); one green témoin always says where you are (Rhythm Machine); green floods only what is selected or available (Glazier); « Trouvé. » lands last like a stamp (Spy Dossier). Signature interaction: the logo's two halves interlocking (separation → search → approach → connection → stabilisation).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
